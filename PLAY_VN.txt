QUICK START - Play Old Bugs Demo
---------------------------------

Option 1 - Command Line (RECOMMENDED):
  cd renpy_sdk
  ./renpy.sh ../vn_projects/old_bugs_demo

Option 2 - Launcher Script:
  ./vn_projects/old_bugs_demo/launch_vn.sh

Option 3 - Ren'Py Launcher GUI:
  cd renpy_sdk
  ./renpy.sh
  (Then select "old_bugs_demo" from the project list)


CREATE NEW VISUAL NOVELS
-------------------------

Convert any analyzed book to a VN:

  python create_visual_novel.py output/BookName [optional_project_name]

Example:
  python create_visual_novel.py output/The_Complete_Works_of_H.P._Lovecraft lovecraft_vn

CUSTOMIZATION
-------------

After playing, you can customize:

1. Edit scripts: vn_projects/old_bugs_demo/game/*.rpy
2. Change colors: vn_projects/old_bugs_demo/game/style.rpy
3. Adjust pacing: Change config.default_text_cps in style.rpy
4. Add music: Place .mp3 files in game/audio/
5. Add backgrounds: Place images in game/images/backgrounds/

CONVERT MORE BOOKS
------------------

To convert another book:

1. Analyze book: python analyze_chapters.py books/book.txt
2. Generate images: python generate_character_images.py output/BookName
3. Create VN: python create_visual_novel.py output/BookName

The system automatically:
- Detects mood (Gothic, Noir, Horror, Romance, Adventure)
- Applies appropriate colors and styling
- Organizes all character sprites
- Parses dialogue from narration
- Creates a playable Ren'Py project
